# 국방 AI 활용 아이디어 경연대회 공모 기획서 (고도화본)

## 1. 제안 요약

### 1-1. 아이디어 명
**FALCON (Force-Adaptive Learning for combat Optimization Network)**  
**: 온톨로지 + GNN 기반 전장의 지식 구조화 및 강화학습 최적화 기반 ‘병력 절감형’ 다영역 전장 결심 지원 체계**

### 1-2. 핵심 가치 (The FALCON Approach)
> **“병력 중심 구조에서 지능 중심 구조로의 전환”**

FALCON은 단순 자동화 도구가 아니라, 전장 데이터를 **지식 체계(ontology)**로 구조화하고, 이를 기반으로 **불확실성 인지(Bayesian GNN)**와 **강건한 전술 탐색(Adversarial RL)**을 결합해 지휘관의 결심 품질을 높이는 **인간통제형 AI 전력운용 플랫폼**이다.  
핵심 가치는 다음 3가지다.

1. **최소 병력·최소 피해·최대 임무효과**를 동시에 추구하는 다목적 최적화
2. **지휘관 중심 의사결정 구조 유지(HITL)**를 전제로 한 책임성 있는 AI 운용
3. **시뮬레이션→훈련→제한운용→확산**이 가능한 단계형 실전 전력화

### 1-3. 기술적 기반
FALCON v4.0 저장소를 기반으로 다음 기술 스택이 통합되어 있다.
- **전장 온톨로지(42종 유닛, 교리·C2·ROE 포함)**
- **Bayesian GNN 기반 위협/상태 추정 및 불확실성 분해**
- **적대적 강화학습(Self-Play, PSRO, NFSP, RARL) 기반 전술 생성**
- **Human-in-the-Loop 기반 제약 반영 및 최종 인간 결심 보장**

## 2. 아이디어 개요

### 2-1. 제안 배경
현대전은 지상·해상·공중·사이버·우주가 결합된 다영역 전장으로 전개되며, 병력 중심의 고정형 작전 개념만으로는 전투지속성과 손실 최소화를 동시에 달성하기 어렵다. 특히 실제 작전 환경에서는 다음 조건이 상시 발생한다.

- **전장의 안개(Fog of War)**: 부분관측과 정보 지연으로 실시간 판단 품질 저하
- **불완전·편향 정보**: 정찰 공백, 기만, 센서 오류로 상황 인식의 불확실성 확대
- **초단기 결심 압박**: 시간 압박으로 최적해 탐색보다 경험 의존 의사결정 증가

FALCON은 위 문제를 “**높은 승리 성공률을 유지하면서도 투입 병력과 피해를 절감하는 결심 체계**”로 전환하기 위한 기술 기반을 이미 보유하고 있다.

### 2-2. 목적
1. **임무 중심 전력운용 AI 확립**  
   병력·화력·시간을 통합 고려하는 다목적 최적화로 임무효과 극대화
2. **지휘관 인지부하 및 결심지연 저감**  
   대안 자동생성 + 리스크 비교 + 설명가능 근거 제공
3. **군 제도 수용성 확보**  
   ROE/책임지휘 체계에 부합하는 인간통제형 AI 운용 모델 제시

### 2-3. 아이디어 요약
FALCON은 전장 데이터(유닛 상태, 지형/기상, ISR, 교리 규칙)를 온톨로지-그래프로 통합한 뒤, AI가 병력 절감형 대안을 다수 생성하고, 지휘관이 제약조건(민간피해 최소화, 시간 제한, 탄약 한계, 우군 보호 우선 등)을 반영해 최종 작전안을 선택하는 구조다.

**핵심 특징**
- **병력절감 목적함수 내재화**: 승리확률 + 아군피해 + 투입병력 + 소요시간 동시 최적화
- **다중 대안 제시형 AI**: Pareto Frontier 기반 3~5개 실행 가능한 대안 자동 제시
- **설명가능 의사결정 지원**: AAR·반사실 분석·근거 시각화로 결심 책임성 강화
- **점진적 전력화**: 모의환경부터 제한부대 실증까지 확장 가능한 로드맵 제공

## 3. 세부 기획안

### 3-1. 아이디어 상세 내용

#### 가. 기술적 아키텍처 (6계층)

1. **지식·규칙 계층 (Ontology Layer)**
   - 42종 유닛(전차/포병/UAV/함정/방공/전자전 등), 임무 유형, C2 체계, ROE/IHL 규칙을 표준 스키마로 정규화
   - 객체(유닛)-관계(지휘/지원/위협)-속성(탄약/피로/탐지율)을 그래프 형태로 연결
   - 규칙 충돌(예: 임무 긴급성 vs 민간피해 제한) 발생 시 우선순위 정책 테이블로 해결

2. **시뮬레이션 계층 (Simulation Layer)**
   - 교전·기동·보급·지형·전자기 환경을 포함한 전장 동역학 모델 구성
   - 부분관측 환경(POMDP) 기반 상태 전이 시뮬레이션 및 몬테카를로 반복 평가
   - 적 전술 다양화를 위한 시나리오 팩(기만/우회/포화공격/전자교란) 운영

3. **인지·예측 계층 (Bayesian GNN Layer)**
   - 이종 그래프(Heterogeneous Graph)에서 노드/엣지 임베딩으로 실시간 전장 상태 추정
   - 인식론적 불확실성(모델 미확신)과 우연적 불확실성(관측 노이즈) 분리
   - 신뢰도 점수와 함께 위협 우선순위(예: 고치명/고긴급 목표)를 산출

4. **학습·전술 생성 계층 (Adversarial RL Layer)**
   - Self-Play/PSRO/NFSP/RARL로 비정형 적에 대한 강건 정책 학습
   - 단일 정책이 아닌 임무성향별 정책군(고속 돌파형·저손실형·균형형) 동시 학습
   - OOD(분포 외) 상황에 대한 안전 행동 fallback 정책 탑재

5. **결심 보조 계층 (HITL Layer)**
   - 자연어 지휘의도(“민간피해 최우선, 2시간 내 교두보 확보”)를 제약식으로 변환
   - AI 대안별 기대효과/손실/소요시간/ROE 위험도를 동시 표시
   - 인간이 최종 승인·수정·기각하며 AI는 추천과 근거 제공만 수행

6. **설명·평가 계층 (XAI & Evaluation Layer)**
   - 자동 AAR: 선택안, 대체안, 결과 차이, 원인 분석을 리포트화
   - 반사실 분석: “대안 B 선택 시 피해율/시간/성공확률 변화” 정량 제시
   - 모델감사 로그: 입력 데이터, 모델 버전, 추천 사유, 승인자 기록 보존

#### 나. 핵심 알고리즘 구동 원리 (구체화)

##### 1) 상태 표현: 온톨로지-그래프 변환
- 시점 t의 전장을 그래프 \(G_t=(V_t,E_t,X_t)\)로 표현
  - \(V_t\): 유닛/센서/지형거점/지휘노드
  - \(E_t\): 지휘관계, 지원관계, 위협관계, 통신연결
  - \(X_t\): 전투력, 탄약, 탐지확률, 피격위험, 이동가용성 등 특성
- 온톨로지 규칙으로 누락/충돌 데이터를 보정해 학습 입력 품질을 안정화

##### 2) 불확실성 인지: Bayesian GNN 추론
- GNN으로 노드 상태 \(\hat{s}_t\)를 추정하고, Bayesian 추론으로 신뢰구간 \(\sigma_t\)를 계산
- 모델은 결과를 “예상값+신뢰도”로 출력해 지휘관이 위험수준을 동시에 인지
- 고불확실 구역은 추가 정찰 요청 또는 보수적 전술 우선 추천

##### 3) 다목적 보상함수 설계
임무 목표를 단일 점수가 아닌 다목적 벡터로 구성:
\[
R = w_1\cdot P_{success} - w_2\cdot C_{friendly} - w_3\cdot M_{troops} - w_4\cdot T_{time} - w_5\cdot V_{ROE}
\]
- \(P_{success}\): 임무 성공확률
- \(C_{friendly}\): 아군 피해
- \(M_{troops}\): 투입 병력 규모
- \(T_{time}\): 임무 완료 시간
- \(V_{ROE}\): ROE/IHL 위반 패널티

지휘관 의도에 따라 \(w_i\)를 조정해 동일 상황에서도 작전 대안의 우선순위를 동적으로 변경한다.

##### 4) 적대적 강화학습 루프
1. 아군 정책 \(\pi_f\)와 적군 정책 \(\pi_e\)를 동시 학습(Self-Play)
2. PSRO로 전략 집합을 갱신하며 메타전략 혼합비 최적화
3. RARL로 최악 조건(통신두절, 전자교란, 센서오류)에서도 정책 내구성 강화
4. NFSP로 규칙기반+학습기반을 결합해 과도한 편향 전술 방지

##### 5) 대안 생성 및 Pareto 선택
- 훈련된 정책군으로 3~5개 대안을 생성한 뒤 Pareto Frontier 상 비지배해만 선별
- 각 대안은 다음 정보를 포함해 제시:
  - 성공확률
  - 예상 피해/병력/시간
  - ROE 위험도
  - 주요 실패 시나리오 및 대응책

##### 6) 인간 피드백 반영(HITL Online Adaptation)
- 지휘관 선택/수정 이력을 선호 데이터셋으로 축적
- 선호학습으로 정책 우선순위를 조정하되, 안전제약(ROE/IHL) 위반 영역은 학습 금지
- 결과적으로 시간이 지날수록 부대 성향과 교리에 맞는 추천 정합도 향상

#### 다. 실제 운용 시나리오 (구체화)

##### 시나리오: 해안-도심 연계 방어작전 (72시간)

**상황 가정**
- 적은 상륙 후 도심 관문 장악을 목표로 기동
- 아군은 제한 병력으로 해안 저지+도심 방어를 동시 수행해야 함
- 민간 거주지역 인접으로 화력 사용 제약이 큼

**운용 절차**
1. **T-180분: 초기 상황입력**
   - ISR/C4I 데이터 자동 수집
   - 온톨로지 정규화 후 전장 그래프 생성
2. **T-150분: AI 대안 생성**
   - 대안 A(고속 저지형), B(저손실 지연형), C(균형 기동형) 제시
3. **T-120분: 지휘관 제약 반영**
   - “민간피해 최소, 포병탄 30% 비축, 6시간 내 관문 유지” 입력
   - AI가 대안 우선순위 재정렬 및 병력 재배치안 자동 갱신
4. **T-90분: 결심 및 명령 하달**
   - 지휘관이 B안을 기본으로 C안 일부를 결합해 승인
   - 시스템이 병과별 명령초안/위험경보/보급우선순위 동시 제공
5. **작전 중 실시간 재평가(15분 주기)**
   - 적 전술 변화 감지 시 반사실 분석과 대체기동 추천
6. **작전 종료 후 AAR 자동 생성**
   - 실제 선택안 vs 미선택 대안 비교
   - 피해 원인·성공요인·교리 개선 포인트 도출

**기대 효과(시나리오 기준)**
- 기존 SOP 대비 결심시간 단축, 아군 피해율 감소, 임무 성공률 유지 또는 향상
- 지휘관은 “왜 이 대안을 추천했는가”를 근거와 함께 검증 가능

### 3-2. 차별성 (구체화)

1. **기존 C2 보조 도구와의 차별성**
   - 기존: 상황표시 중심(what happened)
   - FALCON: **대안 생성+결과 예측+제약 반영**(what to do next)

2. **단일 성능지표 AI와의 차별성**
   - 기존: 승리확률 중심 최적화
   - FALCON: **승리확률·피해·병력·시간·준법성** 동시 최적화

3. **블랙박스 추천 시스템과의 차별성**
   - 기존: 추천 근거 불명확
   - FALCON: **AAR/반사실/근거 시각화**로 설명가능성 내재화

4. **완전자율 무기체계와의 차별성**
   - 기존 우려: 인간 통제 약화
   - FALCON: **HITL 강제, 인간 최종결심 원칙**을 구조적으로 내장

5. **도입 전략의 차별성**
   - 기존: PoC 종료 후 확산 실패 빈번
   - FALCON: **단계별 KPI 게이트** 기반 전력화 로드맵으로 현장 정착 가능성 강화

## 4. 기타

### 4-1. 개념도 (상세 텍스트)

```text
[다원 센서/ISR/C4I 데이터]
   │
   ├─(1) 데이터 정합/정제
   ▼
[온톨로지 지식화 엔진]
   ├─ 유닛(42종), 임무, C2, ROE/IHL 규칙 매핑
   ├─ 충돌 규칙 해소/누락 보정
   ▼
[전장 그래프 생성기]
   ├─ 노드: 아군/적군/중립/지형거점/지휘노드
   ├─ 엣지: 지휘/지원/위협/통신/보급 관계
   ▼
[Bayesian GNN 추론기]
   ├─ 상태추정 + 불확실성(신뢰도) 산출
   ├─ 고위험·고불확실 구역 식별
   ▼
[적대적 RL 전술 생성기]
   ├─ Self-Play/PSRO/NFSP/RARL 정책군 운용
   ├─ 대안 A/B/C (고속/저손실/균형) 생성
   ▼
[HITL 결심 보조 UI]
   ├─ 지휘관 제약 입력(시간/피해/탄약/법규)
   ├─ Pareto 대안 비교표 + 리스크 히트맵 제시
   ├─ 인간 최종 승인/수정/기각
   ▼
[작전 실행 연동]
   ├─ 병과별 임무명령 초안 생성
   ├─ 실시간 재평가(주기 업데이트)
   ▼
[자동 AAR/반사실 분석]
   ├─ 선택안 vs 미선택안 성과 비교
   ├─ 실패원인/개선안/교리 피드백 도출
   ▼
[모델 재학습·감사 거버넌스]
   ├─ 선호학습(HITL 피드백 반영)
   ├─ 버전관리/검증승인/배포통제
```

### 4-2. 정량 성과지표 (권장 목표)

- 투입 병력: 임무 유형별 **10~25% 절감**

- ROE/IHL 치명 위반: **0건 유지**

- 병력절감형 전투개념 정립 및 작전 효율성 향상

## 5. 결론
FALCON은 “AI가 인간을 대체하는 체계”가 아니라, **인간 지휘관의 결심 품질을 높여 병력과 피해를 절감하는 실전형 결심 보좌체계**다. 본 기획안은 기술적 실현성, 제도 수용성, 정량 효과성을 모두 고려한 단계형 계획을 제시하며, 국방 AI 전환의 핵심 목표인 **전투력 유지와 병력절감의 동시 달성**에 직접 기여할 수 있다.
