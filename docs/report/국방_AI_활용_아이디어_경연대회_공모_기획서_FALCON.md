# 국방 AI 활용 아이디어 경연대회 공모 기획서

## 아이디어 명
**FALCON-MSR (Mission Success with Reduced Manpower)**  
**: 병력 절감을 위한 인간중심 다영역 AI 전장 의사결정·전력운용 최적화 체계**

---

## 0. 심사 포인트 정렬형 제안 요약 (한 페이지)

### 한 줄 제안
**“지휘관 결심권은 유지하면서, 병력·피해를 줄이고 임무 성공률을 높이는 실전형 국방 AI 의사결정 보좌체계”**

### 본 제안이 ‘수상 가능성’이 높은 이유
1. **문제 적합성**: “병력 감소 시대의 전투력 유지”라는 군의 최우선 현실문제를 정면으로 다룸
2. **기술 실현성**: FALCON 기존 모듈(온톨로지·Bayesian GNN·적대적 RL·HITL)을 재조합해 단기 시범 가능
3. **정책 수용성**: 인간 최종결심(HITL), ROE/IHL 필터링, 감사로그로 법·윤리 리스크 최소화
4. **정량 성과성**: 성공률·피해율·결심시간·ROE 준수율을 동시에 측정하는 KPI 프레임 제시
5. **확산 가능성**: 모의환경→훈련부대→제한임무→전군 확산의 단계형 전력화 로드맵 보유

### 핵심 산출물(심사위원 체감형)
- **산출물 A**: 작전 대안 3~5개 자동 제시 엔진(고속돌파형/저손실형/균형형)
- **산출물 B**: 지휘관 의사결정 UI(제약 입력·대안 비교·승인)
- **산출물 C**: 자동 AAR 및 반사실 리포트(“다른 대안을 택했다면?”)
- **산출물 D**: 병력절감/피해저감 KPI 대시보드

## 1. 아이디어 개요

### 1) 제안 배경 및 목적
현대 전장은 다영역(지상·해상·공중·사이버·우주) 복합 교전으로 전개되며, 병력 중심의 전통 운용만으로는 전투 지속성과 손실 최소화를 동시에 달성하기 어렵다. 특히 실제 작전에서는 안개전쟁(Fog of War), 불완전·편향 정보, 빠른 상황 변화로 인해 지휘결심 시간이 급격히 줄어든다.

FALCON 저장소에 구현된 기술 스택은 이러한 현실 문제를 “**동일 또는 더 높은 임무 성공률을 유지하면서 투입 병력과 피해를 줄이는 의사결정 체계**”로 전환할 수 있는 기반을 이미 갖추고 있다.

- **다영역 온톨로지 기반 전장 지식 구조화**: 유닛/교리/C2/ROE를 기계가 해석 가능한 구조로 통합
- **Bayesian GNN 기반 불확실성 인지**: 불완전 정보 하에서도 신뢰도 기반 판단 지원
- **적대적 강화학습(Self-Play·PSRO·NFSP·RARL)**: 예측 불가 적 위협에 대한 전술 강건성 강화
- **HITL(Human-in-the-Loop)**: 최종 결심권은 지휘관에게 부여하고 AI는 대안·리스크를 설명 가능한 형태로 제시

본 아이디어의 목적은 다음과 같다.
1. 병력·화력·시간을 동시에 최적화하는 **임무중심 전력 운용 AI** 확립
2. 지휘관의 인지부하와 결심 지연을 줄이는 **설명가능 의사결정 지원** 제공
3. 현행 군 조직·법령 체계(ROE, 책임지휘)에 부합하는 **인간통제형 AI 적용 모델** 제시

### 2) 아이디어 요약
FALCON-MSR은 기존 FALCON 코드베이스를 기반으로, 전장 데이터(정보자산·유닛 상태·환경·교리 규칙)를 하나의 그래프 상태로 통합하고, AI가 병력 절감형 작전 대안을 다수 생성한 뒤 지휘관이 제약조건(민간피해 최소화, 시간제약, 탄약한계 등)을 반영하여 최종안을 선택하는 체계이다.

핵심 특징:
- **병력절감 목적함수 내재화**: 승리확률만이 아니라 아군 피해/투입병력/소요시간을 동시 최적화
- **다중 대안 제시형 AI**: 단일 정답이 아닌 Pareto 최적 대안 세트 제시
- **설명 가능한 전장 AI**: 자동 AAR, 반사실 분석, attention 시각화로 의사결정 근거 제시
- **점진적 전력화 가능**: 시뮬레이션 → 워게임 시범 → 제한부대 실증 → 전군 확산 로드맵 제공

## 2. 세부 기획안

### 1) 아이디어 상세 내용

#### 가. 기술적 아키텍처
FALCON-MSR의 운용 구조는 아래 6계층으로 설계한다.

1. **지식·규칙 계층 (Ontology Layer)**  
   - 전투 단위, 전력 속성, 연합·합동 구조, ROE, 윤리 제약을 온톨로지로 모델링
   - 시나리오 프리셋(한반도 방어, 시가전, 공중우세, 상륙, 사이버/전자전) 기반 표준 실험 가능

2. **전장 시뮬레이션 계층 (Simulation Layer)**  
   - 혼합 란체스터 기반 소모전, 기동, 보급, 전자기 환경, 피격/탐지 확률을 통합
   - 부분관측(Fog of War) 및 교란 상황에서의 의사결정 내구성 검증

3. **인지·예측 계층 (Bayesian GNN Layer)**  
   - 이종 전투 그래프(Heterogeneous Graph)에서 상태 추정 및 불확실성 분리(인식론적/우연적)
   - “확신 높은 정보”와 “추정 정보”를 분리해 위험 민감형 행동 선택 지원

4. **학습·전술 생성 계층 (Adversarial RL Layer)**  
   - PPO, League Self-Play, PSRO, NFSP, RARL, MAT/HAPPO 등으로 강건 정책 학습
   - 적의 비정형 전술·기만 행동까지 포함한 자기대전 기반 전술 고도화

5. **지휘결심 보조 계층 (HITL Layer)**  
   - 자연어 제약 입력(예: “민간피해 최소, 3시간 내 확보”)을 수학적 제약식으로 변환
   - Pareto 대안(고속돌파형/저손실형/균형형)을 생성하고 선호학습으로 지휘성향 반영

6. **설명·검증 계층 (XAI & Evaluation Layer)**  
   - 자동 AAR, 반사실 시뮬레이션(“이 전술 대신 B를 선택했다면?”), 적대적 벤치마크 제공
   - 실전 적용 전 위험요소를 계량화해 승인 가능한 수준으로 축소

#### 나. 핵심 알고리즘 구동 원리
- **다목적 보상함수**: 임무성공률(+), 아군피해(-), 투입병력(-), 임무시간(-), ROE 위반(-)을 통합
- **Self-Play + PSRO**: 고정 적 모델이 아닌 전략 집합 기반 대응으로 일반화 능력 확보
- **NFSP**: 최선응답(BR)과 평균전략(AS) 병행으로 극단 전략 과적합 억제
- **Bayesian 불확실성 활용**: 불확실성 구간이 큰 지역은 정찰/무인자산 우선 배치로 인명노출 최소화
- **Pareto 최적화**: 단일 점수 극대화가 아닌 병력-시간-성공률 간 트레이드오프를 명시적 제공

#### 다. 실제 운용 시나리오 및 서비스 흐름

**[상황]** 전방 국지도발 징후 발생, 제한 병력으로 핵심 거점 방어 필요.

1) C4I/ISR 데이터 유입 → 온톨로지 정규화  
2) Bayesian GNN이 적 의도/위협축 추정 + 신뢰도 부여  
3) RL 정책이 3~5개 작전대안 자동 생성  
4) HITL 모듈이 지휘관 제약 반영해 대안 재정렬  
5) 지휘관 최종 승인 후 실행, 실시간 재계획(replan) 수행  
6) 작전 종료 후 자동 AAR로 교훈 축적, 다음 임무에 학습 반영

### 2) 차별성
1. **“완전자율 타격”이 아닌 “인간결심 강화형 AI”**  
   - 법·윤리 리스크를 줄이면서 현장 적용성을 높임
2. **다영역+교리+윤리 규칙의 동시 내재화**  
   - 단순 전술 추천 엔진을 넘어 실제 군 운용 규범과 결합
3. **강건성 중심 학습 체계**  
   - 적대적 학습(RARL, Self-Play, PSRO)으로 교란·기만 상황 대응력 강화
4. **설명가능성과 검증 가능성 확보**  
   - “왜 이 결정을 추천했는지”를 전투 후 검증 가능 형태로 제공
5. **병력 절감 목표의 직접 반영**  
   - 기존 체계의 승패 중심 지표에서 벗어나 병력 효율 KPI를 정책학습에 직접 포함

### 3) 실현 가능성

#### 가. 필요한 AI 모델 및 아키텍처
- 전장 상태인식: Bayesian HGT/Temporal GNN
- 행동정책 학습: PPO 기반 + Self-Play + PSRO/NFSP/MAT 확장
- 의사결정 지원: 제약 파서 + Pareto 생성기 + 선호학습기
- 설명/검증: 자동 AAR, counterfactual 분석, 역사·적대 벤치마크

즉, 신규 원천기술 “발명”보다 **현재 저장소 내 구현체 통합·고도화**만으로도 시범체계 구축이 가능하다.

#### 나. 군 데이터 활용 가능성 및 정제 방안
1. **데이터 소스**: 훈련·워게임 로그, 모의교전 결과, 교리문서, 공개 정보(OSINT), 합성 데이터  
2. **정제 파이프라인**: 표준 스키마화 → 이상치 제거 → 시계열 정렬 → 라벨링 품질검증  
3. **온톨로지 기반 통합**: 유닛·임무·지형·ROE 엔티티를 공통 키로 매핑하여 부대 간 데이터 이질성 완화  
4. **보안/비식별**: 민감정보 마스킹, 폐쇄망 학습, 접근권한 분리, 모델 반출통제 적용

#### 다. 현행 법령·제도 내 실행 가능성
- 최종 무력사용 판단은 지휘관(인간)이 수행하는 **HITL 원칙** 준수
- 교전수칙(ROE), 국제인도법(IHL) 위반 가능 행동은 AI 단계에서 선제 필터링
- 단계별 실증(모의환경→교육훈련→제한운용)으로 제도 수용성 확보

### 4) 적용 효과성

#### 가. 직접 기여도
- 동일 임무 기준 **투입 병력/피해 최소화** 전략을 체계적으로 도출
- 지휘결심 시간 단축 및 위험도 가시화로 작전 실패 확률 감소

#### 나. 정량·정성 기대효과(목표 KPI)
- 임무성공률: 기준 전술 대비 **+8~15%p**
- 아군 피해율: 기준 전술 대비 **15~30% 감소**
- 투입 병력 규모: 임무유형별 **10~25% 절감**
- 지휘결심 소요시간: 상황판단~대안선택 단계 **30% 이상 단축**
- 정성효과: 지휘관 신뢰성 향상, 작전설명 책임성 강화, 합동성 증대

※ 상기 수치는 시뮬레이션·워게임 실증 단계에서 시나리오별로 재보정한다.

#### 다. KPI 측정 체계(심사용 정량화 표)

| 평가영역 | 지표 정의 | 기준선(Baseline) | 목표(Target) | 검증 방법 |
|---|---|---:|---:|---|
| 임무 달성 | Mission Success Rate | 기존 SOP/휴리스틱 | +8~15%p | 동일 시드 몬테카를로 1,000회 |
| 인명 손실 | Friendly Casualty Rate | 기존 SOP/휴리스틱 | -15~30% | 시나리오별 평균+분산 분석 |
| 병력 효율 | Troops per Mission | 임무유형별 평균 | -10~25% | 임무군별 정규화 비교 |
| 의사결정 | Time to Decision | 작전통제실 평균 | -30% 이상 | 로그 타임스탬프 계측 |
| 준법성 | ROE/IHL Violation | 수동 검토 결과 | 0건(치명), 경미 -50% | 규칙 엔진 + 사후 감사 |
| 신뢰성 | OOD 성능 하락폭 | ID 대비 성능 | 하락폭 10% 이내 | OOD 시나리오 스트레스 테스트 |

### 5) 추진 전략

#### 단계 1: 기술 고도화 (0~4개월)
- 병력 절감 KPI 중심 보상 재설계
- 시나리오별(도심/해안/산악/전자전) 학습·평가 파이프라인 자동화
- 안정성 테스트(수치안정성, 재현성, 분포외 상황) 강화

**단계 산출물**: 학습 모델 v1, 평가 리포트 v1, 대안생성 API

#### 단계 2: 시범 운용 (5~8개월)
- 교육사/훈련부대 워게임 환경 연동
- 지휘관 UI 기반 대안 제시·선택 실험(HITL)
- AAR 기반 전술개선 루프 운영

**단계 산출물**: 시범 UI, 지휘관 피드백 리포트, AAR 자동화 모듈

#### 단계 3: 제한 전력화 (9~14개월)
- 특정 임무군(방어작전/기동지연작전 등)에 한정 적용
- 운영절차(SOP), 책임체계, 보안절차 문서화
- 성능·안전성 합격 기준 충족 시 적용 범위 확대

**단계 산출물**: 제한운용 승인 패키지(성능·안전·법무 체크리스트)

#### 단계 4: 전군 확산 (15개월~)
- 합동작전본부/각 군 도메인별 커스텀 모델 배포
- 모델 업데이트 거버넌스(버전관리·감사로그·재학습 승인체계) 정착

**단계 산출물**: 전군 배포 가이드, 표준 MLOps/모델감사 지침

#### 예상 제약 및 대응
- **제약 1: 실데이터 접근 제한** → 합성데이터·시뮬레이션 선학습 + 제한 데이터로 미세조정
- **제약 2: 현장 신뢰 부족** → 설명가능 결과와 사람-검증 루프를 의무화
- **제약 3: 계산자원 부담** → 경량 모델·단계형 추론(긴급 모드/정밀 모드) 적용
- **제약 4: 법/윤리 우려** → HITL 강제, ROE 위반 탐지 자동화, 감사로그 상시 기록

#### 운영 인력·자원 계획(요약)
- **AI 연구/개발**: 4명 (강화학습 2, 그래프학습 1, MLOps 1)
- **군사도메인/교리 자문**: 2명
- **평가·검증/보안**: 2명
- **총 8명 셀 조직**, 14개월 기준 단계형 투입

### 6) 심사위원 설득용 실증/발표 패키지

#### 가. 10분 데모 시나리오(권장)
1. **문제 제시(1분)**: 병력 감소와 결심시간 압박 데이터 제시
2. **기술 소개(2분)**: 온톨로지→GNN→RL→HITL 파이프라인 애니메이션
3. **실시간 대안 생성(3분)**: 동일 상황에서 3개 전술 대안 비교
4. **지휘관 제약 변경(2분)**: “민간피해 최소” 입력 시 전술 재정렬 시연
5. **결과 검증(2분)**: AAR 및 KPI 개선 수치 제시

#### 나. 심사표 대응 매핑(예시)
- **창의성**: 다영역 온톨로지 + 적대적 RL + HITL 통합
- **실현가능성**: 기존 FALCON 모듈 기반, 4단계 일정/산출물 명시
- **효과성**: KPI 수치·측정법·검증프로토콜 동시 제시
- **확산성**: 제한임무→전군 확산 로드맵 및 거버넌스 포함

#### 다. 제출 부속자료 권장 목록
- 부록 A: KPI 산정 기준서(지표 정의·계산식·샘플 로그)
- 부록 B: 윤리·법무 체크리스트(ROE/IHL/HITL 준수 항목)
- 부록 C: 위험관리 매트릭스(발생가능성×영향도×완화계획)
- 부록 D: 단계별 예산·인력표(월별 투입계획)

## 3. 기타

### 가. 개념도(텍스트)
```
[ISR/C4I 입력]
   -> [온톨로지 정규화]
   -> [Bayesian GNN 위협 추정]
   -> [적대적 RL 대안 생성]
   -> [HITL 제약 반영/Pareto 선택]
   -> [지휘관 승인/작전 실행]
   -> [자동 AAR/반사실 분석]
   -> [정책 재학습]
```

### 나. 시뮬레이션·검증 계획
- Monte Carlo 반복실험으로 평균 성능뿐 아니라 꼬리위험(CVaR) 관리
- 역사형 시나리오 + 적대형 벤치마크 병행으로 과적합 방지
- 단계별 기준(성공률·피해율·결심시간·ROE 준수율) 미달 시 배포 보류
- 실증 전 **레드팀 모의교란 훈련**을 의무화하여 취약 정책 사전 제거

### 다. 기대 파급효과
- 병력절감 중심 전투개념 정립으로 국방 AI의 실효성·책임성을 동시 강화
- 유·무인 복합전투(MUM-T) 및 미래 지휘통제체계(JADC2 유사 환경)로 확장 가능
- 국내 국방 AI 생태계(데이터-모델-검증-운영) 표준화의 기반 제공

## 결론
FALCON-MSR은 이미 구현된 FALCON의 핵심 모듈(온톨로지, 시뮬레이터, Bayesian GNN, 적대적 RL, HITL, 평가체계)을 병력 절감이라는 명확한 작전목표로 통합한 제안이다.  
핵심은 “AI가 지휘를 대체”하는 것이 아니라, **지휘관이 더 적은 병력으로 더 안전하고 성공확률 높은 결심을 내리게 하는 전장 의사결정 증강체계**를 구축하는 데 있다.

또한 본 기획서는 심사 관점(창의성·실현가능성·효과성·확산성)에 맞춰 정량 지표, 단계별 산출물, 데모 시나리오, 위험통제 계획까지 구체화하였으므로, 단순 아이디어를 넘어 **즉시 검증 가능한 실행형 제안서**로 기능한다.
